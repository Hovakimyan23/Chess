# Chess Moves Trainer

**Description:**
A mini application for practicing chess piece moves. Select a piece, click on any square, and all possible moves from that square are highlighted.

**Features:**
- Generates an 8×8 chessboard.
- Highlights all valid moves for the selected piece.
- Supports all six chess pieces:
  - ♚ King — one square in any direction
  - ♛ Queen — any number of squares along rank, file, or diagonal
  - ♜ Rook — any number of squares along rank or file
  - ♝ Bishop — any number of squares along diagonals
  - ♞ Knight — L-shaped jumps
  - ♟ Pawn — forward moves, two-square first move, diagonal captures
- Shows the selected square in a distinct color.
- Clears highlights on each new click and when switching pieces.

**Technologies:**
- HTML
- CSS (Grid, Flexbox, transitions)
- JavaScript (DOM, events, arrays)

**How to use:**
1. Open index.html in your browser.
2. Choose a piece from the dropdown.
3. Click on a square to see its valid moves highlighted.
