# Chess Moves Trainer 

**Description:**  
A mini application for practicing chess piece moves. Currently, the knight is implemented. When you click on a square, all possible moves for the selected piece are highlighted.

**Features:**  
- Generates an 8×8 chessboard.  
- Highlights all valid moves for the knight.  
- Allows selection of a piece (currently only the knight).  
- Clears highlights on each new click.

**Technologies:**  
- HTML  
- CSS (Grid, Flexbox)  
- JavaScript (DOM, events, arrays)

**How to use:**  
1. Open index.html in your browser
2. Select a piece and click on a square to see its valid moves.
